# SQL Business Scenarios and Case Studies

This repository contains business-oriented SQL practice built around customers, products, orders, sales, employees, and sales team performance.

## Project Overview
Unlike topic-only SQL practice, this repository is structured around realistic analyst-style questions such as customer behavior, revenue reporting, sales trends, ranking, duplicate handling, subqueries, CTEs, indexing, and monthly reporting.

## Topics Covered
- Filtering and sorting
- Aggregation and grouped reporting
- Joins
- Built-in date and string functions
- Single-row subqueries
- Multi-row subqueries
- Correlated subqueries
- CTEs
- Window functions
- LAG / LEAD
- DENSE_RANK
- Indexing concepts
- Business reporting questions

## Databases Used
- Sales Analytics DB
- SQL Company DB
